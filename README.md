# La Pacheca - Beachfront Dining Experience

Frontend project for a premium chiringuito concept in Malaga, built as a fully responsive single-page experience focused on international tourism.

## Product Focus

- Premium beachfront positioning with modern Mediterranean identity
- Conversion-oriented structure for visitors planning lunch, dinner, or reservations
- Multilingual content strategy for European travelers

## Languages Used

- JavaScript (ES Modules)
- HTML5
- CSS3 with Tailwind CSS utility system

## Technology Stack

- React 19
- Vite 8
- Tailwind CSS 3
- PostCSS + Autoprefixer

## Experience Highlights

- Mobile-first responsive layout
- Component-based architecture for scalability
- Dynamic language support (English, Spanish, German)
- Scroll reveal motion system with reduced-motion accessibility support
- Structured SEO metadata and schema markup
- PDF menu entry point integrated in navigation

## Project Structure

- src/components/layout: global layout blocks (navigation and footer)
- src/components/sections: page content sections
- src/components/ui: reusable UI primitives
- src/components/seo: structured metadata layer
- src/data/siteData.js: localized content model and section data
- public/assets: static images and downloadable menu assets

## Brand and Content

Copywriting, navigation labels, and section messaging are optimized for international travelers, with English-first usability and localized alternatives.

## Deployment Notes

Environment-ready metadata fields are included for canonical URL and social preview configuration.
